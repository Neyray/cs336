## 三、训练流程 · 文件调用顺序

入口是 `cs336_basics/train.py`，它按下图串起其余模块：

```
train.py  (__main__)
  ├─ parse_args()                         # 解析命令行超参
  ├─ np.memmap(train/val .bin)            # 惰性加载 token 数据
  ├─ TransformerLM(...)          ← modules.py        # 建模型
  ├─ AdamW(...)                  ← optimizer.py      # 优化器
  ├─ (可选) load_checkpoint()    ← checkpoint.py     # --resume 续训
  └─ 训练循环 (每个 iteration):
        get_lr_cosine_schedule() ← lr_schedule.py    # 学习率
        get_batch()              ← data_loading.py   # 取一个 batch
        model(inputs)            ← modules.py        # 前向
        cross_entropy()          ← loss.py           # 损失
        loss.backward()                              # 反向
        gradient_clipping()      ← gradient_clipping.py
        optimizer.step()                             # 更新参数
        save_checkpoint()        ← checkpoint.py     # 存 .pt
```

前置产物由两步生成：**① 训练 BPE 分词器 → ② 编码为 .bin**。

```
train_bpe_*.py  →  bpe.py: train_bpe()          # 产物: *_vocab.pkl, *_merges.pkl
encoded_dataset.py (__main__) → tokenization.py: Tokenization.from_files()
                                              + encode_iterable()   # 产物: *.bin
```

### A. TinyStories 训练（已完成，命令留档）

```bash
# ① 训练 BPE（vocab=10000）
python script/train_bpe_tinystories.py

# ② 编码为 .bin
python -m cs336_basics.encoded_dataset \
  --input data/TinyStoriesV2-GPT4-train.txt \
  --vocab tinystories_vocab.pkl \
  --merges tinystories_merges.pkl \
  --output data/tinystories_train.bin

python -m cs336_basics.encoded_dataset \
  --input data/TinyStoriesV2-GPT4-valid.txt \
  --vocab tinystories_vocab.pkl \
  --merges tinystories_merges.pkl \
  --output data/tinystories_valid.bin

# ③ 训练模型
python -m cs336_basics.train \
  --train_data data/tinystories_train.bin \
  --val_data   data/tinystories_valid.bin \
  --vocab_size 10000 \
  --context_length 256 \
  --d_model 512 \
  --num_layers 4 \
  --num_heads 16 \
  --d_ff 1344 \
  --max_iters 10000 \
  --batch_size 32 \
  --checkpoint_dir checkpoints/tinystories \
  --device cuda
```

## 四、文本生成流程 · 文件调用顺序

入口 `cs336_basics/generate.py`，把分词器、模型、权重、解码串起来：

```
generate.py  (__main__)
  ├─ Tokenization.from_files(vocab.pkl, merges.pkl)  ← tokenization.py
  ├─ TransformerLM(与训练相同配置)                    ← modules.py
  ├─ torch.load(checkpoint) → load_state_dict         ← checkpoint 权重
  ├─ model.to(device) ; model.eval()
  └─ decode(model, tokenizer, prompt, ...)            ← decoding.py
        ├─ tokenizer.encode(prompt)
        ├─ 循环: (裁剪到 context_length) → model(ids)
        │          → logits[:, -1] → softmax
        │          → temperature / top-p → 采样 next_token
        ├─ 命中 eos_id 停止
        └─ tokenizer.decode(ids)  返回文本
```

### A. TinyStories 生成（已验证可运行）

```bash
python -m cs336_basics.generate \
  --checkpoint checkpoints/tinystories/checkpoint_10000.pt \
  --vocab tinystories_vocab.pkl \
  --merges tinystories_merges.pkl \
  --vocab_size 10000 \
  --prompt "Once upon a time" \
  --max_tokens 256 --temperature 0.8 --top_p 0.95 --device cuda
```

示例输出（节选）：
> *Once upon a time, there was a chubby rabbit named Remy. Remy loved to hop and play all day long...*

## 五、附录：TinyStories checkpoint 的模型配置

生成时必须与之一致（OWT 仅 `vocab_size` 改为 32000）：

| 参数 | 值 | 参数 | 值 |
|------|----|------|----|
| vocab_size | 10000 | num_heads | 16 |
| context_length | 256 | d_ff | 1344 |
| d_model | 512 | rope_theta | 10000.0 |
| num_layers | 4 | iteration | 10000 |

**一句话记忆**：训练 = `train.py` 串起 modules/optimizer/loss/... → checkpoint；生成 = `generate.py` 串起 tokenization → modules → checkpoint → decoding。两个数据集流程一致，只有词表大小、文件名、数据量不同。
